# Olympiad media

Video for scottsdaleolympiad.com and social, built in code with [Remotion](https://www.remotion.dev).
Same colors, fonts and photos as the website, so the video *is* the Olympiad brand in motion.

## What's here
| Composition | Size | Use |
|---|---|---|
| `Explainer-16x9` | 1920×1080, 33s | Website, YouTube, email |
| `Explainer-9x16` | 1080×1920, 33s | Instagram Reels / Stories, LinkedIn mobile |

Script, about 30 seconds:
1. **Open (0–5s):** Every spring, Arizona businesses trade the office… for the field.
2. **What (5–11s):** This is the Olympiad. A corporate field day at Scottsdale Stadium, hosted by the Saguaros.
3. **Impact (11–18.5s):** Every team raises at least $3,000 for Arizona's kids. Last year? Nearly $700K.
4. **How (18.5–24.5s):** Getting in is simple. Register your team. Bring six or more coworkers. And fundraise your way.
5. **Close (24.5–33s):** Cups for top fundraisers. Medals for game winners. Register today at scottsdaleolympiad.com.

## Render
```bash
cd olympiad-media
npm install
npm run studio          # live preview and scrubbing in the browser
npm run render          # writes out/olympiad-explainer-16x9.mp4 and -9x16.mp4
npm run render -- stills  # poster frames only
```

## Change something
- **Words on screen / timing:** `src/Explainer.tsx`. Every cue is in seconds and matches the voiceover word timings (`audio/word_timings.py` prints them).
- **Scene lengths:** `SCENES` in `src/theme.ts`.
- **Colors and fonts:** `src/theme.ts` (fonts are bundled in `public/fonts`).
- **Photos:** `public/img`.

## Audio
`public/audio/explainer-mix.wav` = voiceover + music, mixed by `audio/mix.sh`.

- **Voiceover:** [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0) neural voice `af_heart`, speed 1.05, generated by `audio/voiceover.py` (`pip install kokoro-onnx soundfile`, then download `kokoro-v1.0.onnx` and `voices-v1.0.bin` from the kokoro-onnx GitHub release into `audio/models/`) and placed on the timeline by `audio/place_vo.py`. Stem: `audio/stems/voiceover.wav`.
- **Music:** an original bed composed for this video in code (`audio/music.py`, D major, 104 BPM, drops on "Cups for top fundraisers"). Stem: `audio/stems/music-bed.wav`.
- **Upgrade path:** to use a human voice or licensed track, export a WAV that follows the same timing (voice lines start at 0.6s, 5.0s, 11.3s, 18.6s and 24.6s), replace the stem, run `audio/mix.sh`, then `npm run render`.
